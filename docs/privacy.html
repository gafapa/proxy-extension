Proxy Privacy Policy

Last updated: May 6, 2026

Overview

Proxy is a Chrome extension that lets authorized pages send user-initiated HTTP requests through the extension runtime. The extension is designed for controlled development and integration workflows where a web page needs a local browser bridge for cross-origin requests.

Data handled by the extension

The extension may process the following data locally in Chrome:

  • Extension settings, including request limits, interface language, allowed HTTP methods, and authorized page patterns.
  • Request metadata and request bodies provided by an authorized page when the user or calling application starts a bridge request.
  • Response status, headers, and response body returned from the target server for that request.

Storage

Settings are stored with Chrome extension storage. Proxy also stores a local audit trail for the latest 20 requests, including the caller origin, HTTP method, target URL without its query string or fragment, status, size, and timing metadata. Request bodies and response bodies are not stored. Proxy does not create user accounts or maintain an external database.

Sharing and transmission

Proxy does not sell, rent, or transfer user data to advertising platforms, data brokers, or analytics providers. Network requests are sent only to the target URL supplied by an authorized page as part of the extension's single purpose.

Permissions

The extension requests broad HTTP and HTTPS host access because its user-facing purpose is to perform bridge requests to user-selected web endpoints. Access is limited by the extension's bridge validation, authorized caller pages, configured request limits, and Chrome's extension permission model.

Limited Use disclosure

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For privacy or support requests, use the support contact configured in the Chrome Web Store developer dashboard for this item.
